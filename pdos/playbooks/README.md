# Playbooks

**Version:** 0.1
**Status:** Platzhalter

## Zweck

Schritt-für-Schritt-Anleitungen für definierte, wiederkehrende Szenarien — z. B. "Wie wird ein neuer Blogartikel veröffentlicht", "Wie wird ein Redesign-Branch sauber zusammengeführt" oder "Wie wird auf einen gefundenen Sicherheitsfund reagiert". Playbooks unterscheiden sich von Checklisten dadurch, dass sie den Prozess erklären, nicht nur Punkte zum Abhaken liefern.

## Geplante Inhalte (noch nicht ausgearbeitet)

- Playbook: Blogartikel veröffentlichen
- Playbook: Redesign-Branch mergen
- Playbook: Reaktion auf Sicherheits-/Performance-Funde
- Playbook: Neue Sprache/Locale einführen

*Dies ist ein Platzhalter für Version 0.1. Inhalte folgen in einer späteren Iteration.*
