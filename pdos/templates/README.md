# Templates

**Version:** 0.1
**Status:** Platzhalter

## Zweck

Wiederverwendbare Vorlagen für wiederkehrende Dokumente: Briefings, Reports, Feature-Beschreibungen, Content-Vorlagen und Ähnliches. Ziel ist, dass gleichartige Dokumente immer in derselben Struktur entstehen, statt jedes Mal neu erfunden zu werden.

## Geplante Inhalte (noch nicht ausgearbeitet)

- Feature-/Änderungs-Briefing-Vorlage
- Content-/Blogartikel-Vorlage
- Design-Review-Vorlage

*Dies ist ein Platzhalter für Version 0.1. Inhalte folgen in einer späteren Iteration.*
