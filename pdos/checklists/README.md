# Checklists

**Version:** 0.1
**Status:** Platzhalter

## Zweck

Konkrete, abhakbare Prüflisten für wiederkehrende Aufgaben — etwa vor einem Release, beim Hinzufügen einer neuen Sprache, beim Veröffentlichen eines Blogartikels oder bei einer neuen Design-Komponente. Checklisten machen die Prinzipien aus [`00-core`](../00-core/README.md) im Alltag konkret anwendbar.

## Geplante Inhalte (noch nicht ausgearbeitet)

- Pre-Release-Checkliste (SEO, Accessibility, Performance, Legal)
- Checkliste für neue Übersetzungs-Keys (`de`/`en`/`fr`)
- Checkliste für neue Website-Komponenten
- Checkliste für neue Blog-/Situations-Inhalte

*Dies ist ein Platzhalter für Version 0.1. Inhalte folgen in einer späteren Iteration.*
